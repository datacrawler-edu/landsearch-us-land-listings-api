# Run in Apify Console

1. Open the [Actor](https://apify.com/datascraperes/landsearch-us-land-scraper?fpr=edudata).
2. Enter a U.S. location or open the alternative section for individual property URLs. Clear Location and the location filters when using URLs.
3. Adjust the optional limit or filters and select **Start**.
4. Check the run summary, then open **Dataset** and export JSON or CSV.
